# 模特图多原图

日期：2026-10-22。

- 模特图右侧原图区域支持多张；素材池可多选后加入，追加到已有原图并按原图地址去重。
- 本地上传支持一次选择多张，与素材池图片混用。通过 `/flycowerp/temp-image/upload` 取得原图、预览及缩略图地址后追加；失败保留已有图片，继续处理本次其他文件。
- 每张原图支持移除及前后排序。整体保存与恢复保留全部原图和顺序，保存仍不做必填校验。
- 沿用现有字符串参数：`originalImg`、`previewOriginalImg`、`smallOriginalImg` 按相同顺序使用逗号连接。生图数量及 `type` 仍表示生成结果数量，与输入原图数量无关。
- 独立图片生成弹窗保留原有单原图交互，参考图仍支持多张。

验证脚本：`docs/testing/model-generation-workspace-2026-10-22/browser.mjs`，覆盖素材池多选追加和去重、多文件上传部分失败、混合来源排序移除、三种地址对应、整体保存恢复和生图请求，以及原有款式隔离、参考图、结果图和独立弹窗回归。浏览器使用模拟接口，不创建真实生图任务。
