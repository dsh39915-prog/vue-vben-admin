# 生图来源字段更新

日期：2026-10-22，按后端更新说明接入。

- 保存、修改、列表查询及详情类型使用 `sourcePage`，移除旧 `imgType`。
- 来源枚举：0 单图生成、1 批量生成、3 线稿生图、4 材质增强、5 模特图、6 动作图。
- 普通新建生图按生成数量设置 0/1；模特图、动作图工作区固定为 5/6，不受生成数量及历史草稿影响。编辑已有记录保留返回的来源，缺失时按数量补齐。
- 生图列表及任务中心的来源筛选提供全部六种选项。
- 浏览器模拟回归验证普通单图/批量保存、两种流程节点多张生成、列表六种来源查询，断言请求不含 `imgType`；类型检查、ESLint 和差异空白检查通过。未写入真实业务数据。
