# AI图片审核（模特图）工作区

日期：2026-10-22。以用户提供的审核页参考图为布局依据，接口核对来源为 `http://192.168.0.140:48080/v3/api-docs/flycowerp`。

## 页面

- 审核节点处理页沿用任务及当前节点信息，按款式（颜色）折叠展示，默认展开第一款。
- 左侧展示 AI 方案素材池：方案图、模特图、场景图、主参考图、服装商品图、道具、全身、光线、版型、其他参考及 AI 方案成图。正侧背归为一组，图片可放大，缺失素材不占位，可打开整体方案预览。
- 右侧展示该款式已保存的模特图及服装细节对照图，不展示全部生图批次、未提交草稿或生图操作。
- 每个款式独立确认“AI模特图与服装商品图衣服细节一致”。通过前需所有款式都有模特图和对照图，并确认细节一致；驳回无需勾选。
- 底部统一填写审核意见（必填、最多 1000 字）、上传最多 6 张附件，并提供取消、驳回、通过。附件复用文件上传接口，失败保留意见、附件和确认状态。
- 上传或审核期间禁用重复操作和任务切换；写入前重新查询当前员工范围，校验流程、节点及节点任务 ID。已流转或被冻结的任务不能继续审核；成功返回当前节点列表。
- 仅调整模特图审核处理页，其他审核节点和只读流程详情沿用现有入口。

## 接口与数据

| 用途 | 接口与约定 |
| --- | --- |
| 当前任务的款式 | GET `/flycowerp/newProductStyle/list?taskId=…` |
| 搭配方案素材 | GET `/flycowerp/aiMatchingScheme/list?taskId=…`，按款号和颜色匹配 |
| 已保存的模特图 | GET `/flycowerp/newProductStyle/queryMatchStyleList?styleNo=…`，取 `aiModelImageUrls`；按当前任务的款式 ID 及款号精确匹配，不能直接展示模糊查询的其他候选 |
| 细节对照图 | 当前任务款式的 `clothingProductUrl` |
| 审核附件 | POST `/flycowerp/temp-image/upload`，保留三个地址及 `imageId` |
| 提交审核 | POST `/flycowerp/flow/audit`；`nodeKey=aiImageModelAudit`，`auditStatus=1/2`，携带完整节点上下文、审核意见和附件 |

`aiModelImageUrls` 同时兼容图片数组与实际接口可能返回的 JSON 数组字符串；格式错误阻止审核并支持重新加载。款式 ID 按字符串比较，保留大整数精度。

## 后端待补

1. 当前 `newProductStyle/list` 的 Schema 仍没有已提交的节点图片字段，本页通过现有按款号查询接口读取 `aiModelImageUrls`。如需区分多次退回后的提交版本，应提供对应节点任务的图片及提交版本查询约定。
2. 参考图最下方的“补拍静物图（无水印，静物拍摄正侧面）”没有独立字段或接口，不推断现有其他素材为补拍静物图；当前展示实际提供的素材。细节校验暂以 `clothingProductUrl` 为对照，后续有独立静物图字段时再替换数据来源。
3. 通用审核接口没有细节确认字段，复选框仅为本次页面通过前的确认，不持久化、不伪造接口参数。后续若需归档逐款校验结果，需后端补充字段。
