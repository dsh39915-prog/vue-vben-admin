## 前端行为

- 复用认证请求客户端，接收 Blob 和响应头；下载请求超时单独设为 120 秒，为服务端打包留出时间。
- 有效文件通过浏览器保存；文件名优先使用 `Content-Disposition` 中 UTF-8 `filename*`，其次普通 `filename`。无可用响应名时回退为“款号-素材”；识别 ZIP 文件签名后补 `.zip`。不自行生成或改变素材包内容。
- 收到 JSON 业务错误时显示服务端消息；HTTP 错误同样能解析 JSON Blob。业务 401 保留现有令牌刷新及重试流程。
- 空文件、旧的 JSON Boolean、JSON null 和 HTML 等无效响应不会保存为文件。界面不将接收文件等同于用户已经完成保存。
- 下载中复用忙碌状态，禁止重复请求和切换任务；结束或失败后恢复操作，保留备注及上传内容，可手动重试。
- 跨域读取服务端文件名需要后端暴露 `Content-Disposition`（`Access-Control-Expose-Headers`）；无法读取时使用回退名，不阻止文件下载。
