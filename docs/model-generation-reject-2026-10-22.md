# AI图片生成（模特图）驳回上一节点

日期：2026-10-22。

用户确认：制作节点的驳回同样使用 `POST /admin-api/flycowerp/flow/audit`。

- 模特图工作区底部操作为“驳回 / 取消 / 保存 / 提交”。驳回有二次确认，复用底部备注作为驳回原因，不能为空；最多 1000 字、6 张附件，附件校验临时图片 ID 与三种地址。
- 无需先选模特图或补齐提示词、模型等生图必填字段。驳回不触发生图、草稿保存或节点图片提交。
- 确认后核验当前员工任务范围、节点状态和流程上下文，防止操作已变更的节点任务；当前 `procInstId/nodeTaskId/nodeKey` 一并传入，`nodeKey=aiImageModelTask`，`auditInfoVO.auditStatus=2`，意见去首尾空格，附带备注附件。
- 具体上一节点由后端流程引擎决定，前端不指定目标节点。成功返回当前节点列表并刷新；接口失败或返回 false 时保留全部参数、选图、备注和附件。
- 请求期间阻止重复操作及离开页面；冻结或只读任务不提供驳回按钮。

模拟接口浏览器验证：无选图可驳回、空原因拦截、取消确认不写入、失败/false 保留输入、节点任务 ID 变化阻止请求、携带原因附件与完整上下文、处理中导航保护、成功返回列表、冻结及只读限制。另回归原有生成、整体保存、恢复及提交，并执行类型检查、ESLint/格式检查、生产构建、补丁空白检查。

测试使用模拟接口，未对真实业务任务执行驳回；真实流程引擎退回结果尚未验收。记录：`docs/testing/model-generation-reject-2026-10-22/`。
