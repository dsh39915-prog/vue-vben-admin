# 页面制作：驳回、保存与提交

2026-10-23，页面制作参考修图制作补齐底部三项操作，无需勾选款式。下载素材入口继续保留。

- **保存**：调用通用节点表单暂存 `/flycowerp/flow/draft/save`，不进行必填校验，不推进流程。保存所有款式的五张主图位置、详情页图、备注、备注附件，重新进入通过 `/flow/draft/get` 恢复。主图空位用 `null` 保存，恢复后不改变顺序；页面制作与修图草稿使用不同的 `formType`。草稿损坏或格式不符时禁止覆盖。
- **提交**：调用 `/flycowerp/newProductStyle/saveImageData`，传当前流程上下文及 `items[].styleId/productMainImageUrls/productDetailImageUrls`。有上传内容的款式必须补齐五张商品主图，并保留“主图1 / 主图2 / 面料3 / 主图4 / 搭配5”顺序；完全未填写的款式跳过。至少提交一款，备注必填、最多 1000 字，附件最多 6 张；点击后提示缺项，通过校验后再确认提交。
- **驳回**：参考修图制作，调用 `/flycowerp/flow/audit`，`nodeKey=pageProduction`、`auditStatus=2`，填写驳回原因及可选附件，无需上传制作图片；确认后由后端执行退回上一节点，成功后回到页面制作列表。

保存、提交、驳回均携带当前 `procInstId/nodeTaskId/nodeKey`，写入前重新检查员工权限、所属节点及节点任务状态。失败保留输入，上传或请求期间阻止重复操作和切换任务。只读详情不获取编辑草稿，不显示三个制作操作。

图片回填：页面制作无该款式草稿时，从 `/newProductStyle/list` 的 `productMainImageUrls`、`productDetailImageUrls` 加载已有图片，主图沿用接口顺序；有该款式草稿时以草稿为准，包括主图空位和用户已清空的详情图，避免恢复已删除图片。草稿未包含的新款式使用接口图片初始化。已验证接口图片显示、保存往返及草稿覆盖优先级。
