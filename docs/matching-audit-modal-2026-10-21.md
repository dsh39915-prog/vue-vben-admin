# AI搭配方案审核弹窗（2026-10-21）

- 制图流程 → AI搭配方案审核，点击列表“审核”直接打开弹窗，不改变列表地址、筛选和页码。冻结任务“查看”打开同一只读弹窗；流程详情仍沿用详情入口。
- 工作台的搭配方案“审核任务”入口也使用相同弹窗，其他节点审核沿用原有操作。
- 根据参考图使用两列素材缩略图，显示款号、款式（颜色）和合拍标识；标明主服饰/搭配服饰，正面/侧面/背面/展现力参考图集中展示。读取已提交方案，不重新生成或修改方案。
- 保留所有已提供的素材，包括全身、光线、版型、AI生成图片。缩略图可放大，多个款式使用单项展开的折叠面板。
- 每款方案右下方增加“整体搭配方案预览”，以新弹层展示当前款式的已提交材料：左侧为服饰/道具、款式信息、场景/模特；右侧为正侧背及展现力参考图、全身/光线/版型/其他参考图。场景等多图完整显示；图片无可见标签，宽度 120px、高度按原比例自动适配，窄屏不超出容器。未提供的图片与空素材分区隐藏，场景在左、模特在右且顶部对齐；“方案成图”可展开查看已有搭配方案图和 AI 生成图片。
- 整体预览不另发请求或修改数据；单图可继续放大，关闭单图、整体预览各返回上一层，审核意见保留。窄屏改为单列，材料较多时只滚动预览内容。
- 审核意见和“取消 / 驳回 / 通过”固定在底部。视口高度不超过 800px 时缩略图缩至 48px；常规高度使用 56px。材料过多时仅滚动素材区，审核附件默认折叠，仍支持最多 6 张。
- 审核意见必填，最多 1000 字；通过/驳回分别提交 `auditStatus=1/2`，复用 `POST /flycowerp/flow/audit`，携带当前流程实例、节点任务 ID、节点 Key 及意见/附件。
- 加载素材前核验节点与员工本人范围，提交前再次核验任务状态、节点任务 ID 和归属。失败保留弹窗、意见和附件；成功关闭并刷新列表。提交或附件上传期间禁止关闭、重复操作及路由切换。
- 冻结、节点上下文不完整时仅查看；无方案或素材加载失败时不允许提交，加载失败可重试。

浏览器模拟已验证：员工固定本人范围、列表 URL 不变、只读素材、全部已提供字段、折叠切换、放大预览、审核必填、通过/驳回参数和附件、失败/false 保留、提交期间保护、成功刷新、节点变化阻止写入、冻结只读、重新分配后不读取素材、加载重试及工作台入口。

整体预览新增回归：两列分区、多张场景图及全身图、隐藏缺图和图片标签、横竖图定宽及原始比例、场景/模特左右顶部对齐、单图放大、按层关闭、审核意见保留、第二款方案对应、窄屏无横向溢出；打开预览不产生接口请求。预览与审核回归、类型检查、ESLint 和格式检查通过。截图：[基础方案](testing/matching-audit-modal-2026-10-21/overall-preview-1366.png)、[完整素材](testing/matching-audit-modal-2026-10-21/overall-preview-full-1366.png)。
