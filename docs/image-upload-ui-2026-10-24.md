# 图片上传界面统一（2026-10-24）

- 本地结果图片、图库上传共用图片选择组件：图标与虚线选择区、拖拽选图、上传前本地预览、点击查看大图、文件名及大小、替换和移除。
- 空文件和非图片文件提示后保留原选图；关闭文件选择窗口也保留原图。替换、移除和卸载组件时释放本地预览 URL。
- 原图、参考图、流程图片及备注附件的上传入口共用图片卡片；保留原有上传顺序、多图数量限制、三种图片地址、上传后预览及图库选择逻辑。
- 上传按钮内部使用明确的局部选择器设置 `display:flex`、纵向排列和居中，避免 Ant Button 的 `.ant-btn > span { display:inline-block }` 覆盖布局。多选提示独立一行。
- 选文件阶段不发结果保存或图库上传请求；提交、上传失败重试沿用原有接口。

## 全页面收敛（2026-10-26）

- 上传入口统一使用 `common/image-upload-trigger.vue`：120×120 虚线卡片。
- 已选图统一使用 `common/image-upload-item.vue`：复用 120×120 缩略图、边框和阴影，统一替换、查看原图、移除的图标、提示和位置。操作按钮放在图片内部，避免在滚动容器中被裁切。
- `WorkflowImages` 移除新旧两套布局的 `compact` 分支；所有流程图片、方案备注、审核附件、分配备注以及修图/页面制作自动使用统一布局。
- 生图原图/参考图、搭配服饰、本地结果上传与图库选图也复用同一图片操作组件。本地选图仍由 `ImageFilePicker` 管理文件和 blob URL，确认上传前只显示本地预览。
- 原图与参考图支持在原位置替换；单图上传后只显示图片上的替换按钮，多图保留追加入口与原有排序功能。主服饰仅可查看，不能替换或移除。

后续图片上传页面应复用上述组件：业务层保留上传接口、数据转换、数量限制和保存时机，避免自行实现上传卡片、缩略图及操作按钮的样式。Excel 等非图像导入保持各自的文件上传交互。

本轮回归脚本：`image-upload-ui-2026-10-24`（含原图替换、参考图多选/替换/排序/移除）、`image-result-upload-2026-10-23`、`matching-style-search-2026-10-22`、`page-production-actions-2026-10-23`、`retouching-actions-2026-10-23`。
