# AI 图片生成（模特图）提交页改造

日期：2026-10-22。

## 页面与操作

- 模特图节点的处理页改为按款式（颜色）展开的工作区；顶部沿用任务信息、当前节点、处理人及逾期情况。
- 左侧展示本款搭配方案素材，支持多选、清空、加入原图或参考图；原图支持多张，加入时追加并按原图地址去重，可与本地多图上传混用。正、侧、背及展现力参考图归为一组，场景图支持多张。缺失素材不占位；搭配方案可整体预览。
- 右侧复用图片生成表单，原图与参考图均通过文件上传接口取得原图、预览、缩略图地址。支持提示词模板、图片模型、模型画质/尺寸/比例、生成数量及立即生成；移除各款式的独立暂存按钮。
- 下方默认展示当前颜色款式的全部批次，可切换批次、刷新、查看历史，沿用本地图片上传必须指定批次的既有功能。
- 生成结果可跨批次勾选提交，切换款式保留各款本次选择，底部统一确认提交。有图片的款式随本次请求提交。按最新要求，模特图页面移除“本款待提交模特图”独立区域；本地图片仍可经批次上传后选择，动作图的待提交区域保留。
- 最底部提供整体保存，允许空提示词、未选模型、空数量、未选图及空备注；保存全部款式右侧参数、跨批次历史选图、本地上传的最终图片、批次筛选、当前展开款式、备注及附件。重新进入读取草稿，未展开款式的数据同样保留。提交时再校验图片与备注。
- 底部增加“驳回”，确认后复用通用审核接口退回上一节点。无需先选图或补齐生图表单，备注作为必填驳回原因，附件一并提交；成功返回当前节点任务列表，失败保留输入。
- 业务条件不足时保持按钮可点击：“提交”先提示缺图、缺备注或图片数据错误，校验通过后才显示提交确认框；确认提交时再次校验。“加入原图/参考图”“清空选择”在未选素材时点击提示。模特图与动作图共用这一交互；上传、请求处理中及只读状态继续防止重复或无权限写入。
- 上传、生成、保存和提交期间阻止切换任务、切换款式和重复操作；失败保留输入，素材或草稿加载失败支持重试。独立图片生成页、其他节点及只读流程详情保持现有入口。

## 接口核对

根据 `http://192.168.0.140:48080/v3/api-docs/flycowerp` 当前契约接入，未新增推测字段。

| 用途 | 接口 |
| --- | --- |
| 款式及主服饰图 | GET `/flycowerp/newProductStyle/list?taskId=…` |
| 已提交搭配方案素材 | GET `/flycowerp/aiMatchingScheme/list?taskId=…` |
| 原图、参考图及最终模特图上传 | POST `/flycowerp/temp-image/upload` |
| 立即生图 | POST `/flycowerp/aiImg/save`，带 `styleId=当前款式ID`、`goodsCode=款号`；最新契约已移除 `businessKey` |
| 整体保存 | POST `/flycowerp/flow/draft/save`，带 `procInstId/nodeTaskId/nodeKey/formDataJson`；不触发生图或节点提交 |
| 草稿恢复 | GET `/flycowerp/flow/draft/get?procInstId=…&nodeKey=…`，解析 JSON 字符串并按款式 ID 恢复 |
| 驳回上一节点 | POST `/flycowerp/flow/audit`，传当前流程上下文、`nodeKey=aiImageModelTask`、`auditInfoVO.auditStatus=2` 及原因/附件；用户已确认制作节点复用此接口 |
| 生成批次及图片 | GET `/flycowerp/aiImageResult/dropdown/{styleId}`、`list/{styleId}[/{imgId}]` |
| 本地结果保存 | POST `/flycowerp/aiImageResult/save`，带 `styleId`、必选 `imgId` 及三种图片地址 |
| 最终模特图提交 | POST `/flycowerp/newProductStyle/saveImageData`，带流程上下文及 `items[].styleId/aiModelImageUrls` |

搭配方案通过款号与颜色同时匹配；不会借用其他颜色的方案。各图片的三种地址保持对应；最终提交只发送模特图接口要求的图片地址。

## 当前后端待补事项

1. 款式关联已通过最新 `styleId` 契约接通，按颜色款式查询历史的问题已解决。当前仍无节点过滤字段，同一款式各节点批次由后端按款式统一返回。
2. 款式列表目前只返回基础款式与主服饰图，没有已提交 `aiModelImageUrls`。模特图审核页现通过 `/newProductStyle/queryMatchStyleList` 读取该字段，并按当前任务款式 ID 精确匹配，详见 `model-audit-workspace-2026-10-22.md`；未提交的参数及最终选图通过通用草稿接口保存、恢复。
3. 用户已确认制作节点驳回复用通用审核接口，现已接入；实际上一节点跳转由后端执行，前端不指定或推断目标节点。整体保存使用通用草稿接口，提交沿用 `saveImageData`。
4. 尚无补拍静物图或任务头部图片的明确读取字段；素材池仅展示现有搭配方案和款式实际返回的图片。
5. 生图列表/详情的响应 Schema 尚未列出 `styleId`；编辑时会保留实际响应中提供的该字段，也可在独立生图弹窗中填写。后端应同步响应字段，保证关联稳定回显。
