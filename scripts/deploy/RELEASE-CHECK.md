## 本次准备改动

- 统一生产服务地址，保持真实 API 路径，清除前端 API 与下载转发依赖。

## 依赖审查范围

审查包含整个工作区的 production dependencies，其中也包含构建、Lint 工具自身的依赖；计数不能直接等同于浏览器产物中的可利用漏洞。本次已清除 Axios、tar、tinypool 的告警以及所有严重级别计数，未声称剩余高危全部无影响。

剩余告警涉及 Vue 的服务端渲染依赖、可选编辑器组件、Zod、Vite 及若干构建工具依赖。部分升级涉及框架或主版本兼容，需要单独评估并回归；没有在上线准备过程中强制跨主版本覆盖。`dependency-audit.json` 保留安装版本、修复版本、依赖路径和公告链接供后续处理。

Docker 镜像未在本机实际构建；已完成脚本语法、隔离行为测试和 Nginx 静态服务测试。具体部署及回滚操作见 [上线说明](RELEASE.md)。
